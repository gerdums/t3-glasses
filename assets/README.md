# Icon

- `icon-24.txt`: the 24×24 Even Hub app icon as a pixel grid (`#` on, `.` off).
- `icon-24.png`: the same grid as an image; `icon-24-preview.png` is a 16× upscale.
- `icon.svg`, `icon-1024.png`, `icon-512.png`: a large version for READMEs and stores.

The design is the G2 display panel from the glasses UI (rounded outline, footer
status dot and line) around "T3".
