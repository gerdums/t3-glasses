# t3-glasses

Show and drive your [T3 Code](https://t3.codes) threads from Even Realities G2
smart glasses: see which threads need you, read the latest messages, approve or
deny tool requests, answer questions, interrupt runs, and reply by voice.

Work in progress. See [docs/architecture.md](docs/architecture.md) and
[docs/glasses-ux.md](docs/glasses-ux.md).
